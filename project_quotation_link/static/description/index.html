Link your sales quotations directly to projects — and track everything from a single Kanban view. No more searching between Sales and Project.

Key Features

Everything you need to connect your projects and quotations

🔗

Direct Quotation Link

Link any sale order to a project directly from the quotation form. One field, instant connection.

📊

Kanban Counter

Each project card shows the number of linked quotations — see your commercial pipeline at a glance without opening anything.

⚡

Smart Buttons

"View Quotations" and "Create Quotation" buttons in the project Kanban menu — navigate instantly without switching modules.

🏢

Custom Project Fields

Add Company, Description and Responsible fields to every project — the information your sales team actually needs.

🔄

Bidirectional Navigation

Go from project to quotations or from quotation to project. The link works both ways, always in sync.

🌍

Multilingual

Available in English, French and Spanish. Works seamlessly with any Odoo language configuration.
