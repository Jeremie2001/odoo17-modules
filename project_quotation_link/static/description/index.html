📌 Project and Quotation Link – Simplified Management

This module allows you to easily link sales quotations to projects and get a clear, complete, and intuitive view of project progress and related quotations.

🚀 Key Features

  • Create custom projects with Company, Description, and Responsible
  • Directly link quotations to a project
  • Kanban view with the number of quotations linked to each project
  • Bidirectional navigation: from a project → see all quotations, and from a quotation → find its project

✨ Benefits for Users

  • Simple and clear project–quotation management
  • Fast and visual tracking via Kanban and smart buttons
  • Intuitive, reliable, and professional module

📌 Example Use Cases

  • Construction: track quotations for electrical, plumbing, and masonry work per project
  • Event Management: group quotations for catering, venue, and providers under one project
  • Software Development: centralize UI/UX, development, and maintenance quotations by project
