📌 Project and Quotation Link – Simplified Management

The challenges you face:

  • Struggling to find which quotations belong to which project?
  • Hard to get a comprehensive overview of your project progress?
  • Complex navigation between projects and quotations in Odoo?
  • Time-consuming search for project-related documents?

✅ The solution:

This module allows you to easily link sales quotations to projects and provides a clear, complete, and intuitive view of project progress and related quotations all in one place.

Key Features

  • ✨ Create custom projects with Company, Description, and Responsible fields
  • 🔗 Direct quotation linking to projects with just a few clicks
  • 📊 Smart Kanban view displaying the number of quotations per project
  • 🔄 Bidirectional navigation: project → quotations and quotations → project
  • ⚡ Smart buttons for quick access and navigation
  • 📈 Visual tracking of project advancement status

📋 How It Works - 3-Step Workflow

1

Create Your Project

Define the client company, add a description, and assign a project manager. Quick and straightforward!

2

Link Quotations to Project

When creating a quotation, simply select the related project. The connection is made automatically.

3

Track via Kanban View

Visualize all your projects at a glance with the number of quotations attached to each one.
