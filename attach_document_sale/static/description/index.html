Auto-Attach Product Documents to Sales Emails

Save time and never forget to send product documents again!

This module automatically attaches product-related documents (catalogs, specifications, images, PDFs, etc.) when sending quotation or sales order emails. It works seamlessly with the standard Odoo mail composer.

Key Features

  • 📎 Automatically detects products in the quotation/sales order
  • 📂 Attaches all related product documents
  • ✅ Avoids duplicate attachments
  • 💡 Works out-of-the-box with Odoo's standard mail composer
  • ⚡ Saves time and ensures customers receive complete documentation

How It Works

1. Configure Product Documents

Attach documents (PDFs, images, catalogs) to products in Odoo.

2. Create a Quotation

Add products that have documents attached.

3. Send Quotation by Email

Open the mail composer from the quotation and the module automatically adds all product-related documents.

4. Customer Receives Complete Documentation

The customer gets the quotation with all relevant product files attached — no extra steps required.

Why Choose This Module?

✔ Reduce mistakes (no forgotten attachments)
✔ Save time for your sales team
✔ Improve customer experience with complete and professional emails

Get Started in Minutes

Simply install the module — no configuration required.

Dependencies: Sales, Mail
