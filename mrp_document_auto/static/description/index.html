MRP — Auto Copy Documents

Stop copying documents manually from components to finished products. This module does it automatically — every time, without errors.

📂 Auto Copy 🔄 Auto Update ⚠️ Obsolete marking ✅ No duplicates

Key Features

Everything you need for automatic document management in manufacturing

📂

Automatic Document Copy

When a Bill of Materials is created or updated, all documents attached to components are automatically copied to the finished product.

✅

No Duplicates

Intelligent duplicate detection by filename and checksum — the same document is never copied twice, keeping your files clean.

🔄

Auto Update

When a component changes, the finished product documents are automatically updated. Always in sync, zero manual work.

⚠️

Obsolete Marking

When a document is deleted from a component, it is automatically marked [OBSOLETE] on the finished product — full traceability.

↔️

Two-way Sync

Bidirectional synchronization between components and finished products — changes propagate automatically in both directions.

📄

All File Types

Works with any file type — PDF, images, DXF, Excel, technical data sheets, certificates. Any attachment is supported.
