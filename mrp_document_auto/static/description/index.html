📂 MRP - Auto Copy Documents

Copie automatique des documents des composants vers le produit fini

Ce module améliore la gestion documentaire dans le module MRP (Nomenclatures / BoM). Il copie automatiquement les pièces jointes liées aux composants (produits ou variantes) vers le produit fini associé. Plus besoin de gérer les documents manuellement !

✨ Fonctionnalités

  • Copie automatique des documents des composants vers le produit final
  • Évite les doublons (contrôle par nom + checksum)
  • Mise à jour automatique lorsque les composants changent
  • Marquage en [LEGACY] des documents supprimés
  • Synchronisation bidirectionnelle avec les produits

🎯 Cas d’utilisation

  • Plans techniques (PDF, images, DXF)
  • Fiches techniques et certificats
  • Documentation de production centralisée

📸 Captures d’écran

✅ Avantages

  • Gain de temps : plus besoin de copier les documents manuellement
  • Moins d’erreurs : documents toujours à jour au bon endroit
  • Transparence et traçabilité complète
